Install Jobtron as an MCP server

Jobtron exposes the same tools and shared application history to Codex, OpenCode, and Claude Code. Install it once per client, then use only one client or agent session at a time.

MCP server namejobtron6900
01

Recommended setup

One command configures every client

uv sync --extra test
uv run jobtron-setup install --clients codex,opencode,claude

The installer safely copies legacy repository data into the shared user data directory when needed, preserves the original as a backup, and writes user-level MCP entries. Select fewer clients with --clients codex, --clients opencode, or --clients claude.

05

Ownership guard

Only one client can own Jobtron

One MCP process

An operating-system lock prevents Codex, OpenCode, Claude Code, or a second session from opening the same Jobtron store concurrently.

Clear conflict message

If Jobtron is already active, the second client reports which client and process owns it instead of racing SQLite or borrowing another frontend.

Automatic release

Closing the owning client releases the operating-system lock. A crash cannot leave a permanently locked database.

06

Diagnostics

If Jobtron does not connect

uv run jobtron-setup doctor
  • Close every other Jobtron-enabled client or session, then restart one client.
  • Run the client-specific verification command from section 02.
  • Run uv run jobtron-setup status to compare legacy, canonical, and runtime data paths.
  • If port 8765 is occupied, close that process or set the same JOBTRON_PORT in the client configuration.
  • The installer backs up an existing OpenCode configuration before rewriting it and never deletes application data during uninstall.
