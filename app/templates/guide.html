01

First use

Connect, restart, verify

1

Restart Codex

Codex loads newly installed MCP servers when the client starts. Restart the desktop app or IDE extension, or begin a fresh CLI session.

2

Check the server

In Codex CLI, run /mcp. In the app or IDE, open Settings → MCP servers and look for jobtron6900.

3

Ask naturally

You do not need to name every tool. Tell Codex to use Jobtron and describe the outcome you want.

codex mcp get jobtron6900

Codex starts the STDIO server on demand. Do not launch a separate workstation: the agent presents Jobtron's review UI inline when it is useful.

02

Recommended loop

Move through an application

  1. State the outcome

    Share a posting, ask to continue existing work, or ask to see the applications Jobtron has made with you.

  2. Let the agent assemble context

    Codex discovers the application, reads candidate sources, records the posting, and follows Jobtron's explicit next action.

  3. Review the result

    After meaningful work, Codex calls ui.show_application. Jobtron presents the authoritative state, readiness checks, and proposed next move.

  4. Confirm or revise

    Your choice returns to the conversation. The agent continues, or asks what should change, then presents a fresh review surface.

  5. Confirm submission

    Only after you confirm external submission may the agent mark the application Applied and freeze its historical snapshot.

03

Prompt recipes

Good ways to ask Codex

Orient
Use Jobtron to list my active applications. Summarize each one and tell me which workspace needs attention first. Do not change anything.
Evaluate fit
Use Jobtron to open application 3. Compare the job requirements with my candidate facts and master resume. Identify strong matches, honest gaps, and the three most valuable improvements. Do not write changes yet.
Continue application
Use the complete context for application 3. Report its progress and blockers, take the next safe action, search the question bank before drafting answers, then ask me the single next question needed to keep moving.
Tailor resume
Use application 3 and my candidate context to create a truthful tailored resume. Save it as a new unapproved application_resume document. Preserve concrete evidence and never invent experience.
Cover letter
Draft a concise cover letter for application 3 using only facts available in Jobtron. Save it as a new unapproved cover_letter document with a clear title.
Final audit
Audit application 3 as a complete package. Check the job description, approved resume and cover letter, questions, current answers, and assets. Report omissions, contradictions, weak evidence, and anything I should review before submitting. Do not modify records.

06

Troubleshooting

If Jobtron is missing in Codex

  • Restart Codex after installation, then check /mcp or Settings → MCP servers.
  • Run codex mcp get jobtron6900 and confirm it is enabled.
  • If the project moved, reinstall the server because its command uses an absolute path.
  • From the project directory, run uv sync --extra test if the virtual environment was removed.
  • Back up data/app.db and data/files/ together.

For Codex configuration details, see the official OpenAI MCP documentation.
